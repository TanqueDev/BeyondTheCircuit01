04 / Interpretación física

ΓL = (ZL − Z0) / (ZL + Z0)
ΓS = (RS − Z0) / (RS + Z0)
V⁺ = Vg · Z0 / (RS + Z0)  ·  td = ℓ / v

Si Γ = 0 no hay reflexión en ese extremo. Si Γ = +1, el voltaje se refleja con la misma polaridad (abierto ideal). Si Γ = −1, se refleja invertido (corto ideal).
